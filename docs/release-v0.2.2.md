# PiliGlass v0.2.2

在同步上游 **PiliPlus 2.2.1** 的基础上，这一版重点优化了液态玻璃的可定制性、底部面板的滑动流畅度，并补齐了日常使用中的几个高频交互细节。

仅支持 **Android arm64-v8a**，签名与之前一致，可直接覆盖安装（Android 8.0 及以上）。

## 上游同步

- 合并上游 **PiliPlus 2.2.1** 代码与依赖更新（含动态详情、回复输入、分集与离线能力等上游修复与改进）。
- 统一各页面顶栏操作胶囊、顶部标签栏与液态玻璃渲染管线的衔接细节。

## 新增「极致液态玻璃微调」

在 **设置 › PiliGlass 特性** 中新增常驻入口 **极致液态玻璃微调**（需将「透明效果」设为「极致」并重启后进入，未开启时会提示：`请先将“透明效果”设为“极致”并重启软件`）：

- **壳体透明与模糊实时调节**：提供「默认 / 清透 / 晶体 / 全透明」四档快捷预设，也可通过滑杆或点击数值精确调整模糊度（0 ~ 6.0）与遮罩不透明度（0% ~ 60%）。
- **折射范围 / 弯曲倍率调节**：提供「关闭 / 微弱 / 默认 / 强烈」预设与 0.00x ~ 2.00x 精细调节，控制液态玻璃边缘折射的宽度与拉伸感。
- **分组件独立开关**：
  - 顶栏圆按钮（返回、操作等）是否跟随壳体透明度（默认开启）。
  - 「...」弹出菜单与底部上拉面板各自是否启用高透效果，以及是否开启边缘折射。
- **所见即所得**：调完参数后无需重启，首页头像、消息按钮、顶部标签栏、底栏、悬浮按钮、弹出卡片及 Toast 都会实时同步变化；底部提供「恢复『极致』默认参数」一键还原。

## 面板流畅度与交互优化

- **底层面板性能优化**：重构发布动态、弹幕设置、收藏夹、播放页设置等底部上拉面板，统一改用和评论区相同的「单次静态背景截图模糊」方案，滑动与展开跟手流畅，不再每帧重算全屏模糊。
- **统一的上下拉手势与动画**：
  - 所有新接入的玻璃上拉面板都支持按住顶部指示条**上拉放大到全屏 / 下拉收起或关闭**。
  - 竖屏播放页右上角 **「...」菜单** 改为从屏幕底部向上弹出的液态玻璃面板（横屏保持暗色浮层体验）。

## 界面细节与快捷重启

- **浅色模式背景统一**：将浅色主题下的全局页面底色调整为更柔和干净的中性浅灰（`#EFEDF0`），减少原本偏粉或发暗带来的灰浊感，覆盖首页、设置页等全部页面。
- **竖屏弹幕输入条对齐**：调整视频竖屏详情页「发个友善的弹幕见证当下」输入框高度，与右侧弹幕开关圆形按钮直径对齐。
- **一键重启软件**：在 **PiliGlass 特性** 页面右上角新增重启按钮，点击弹出「重启软件」菜单，确认后会彻底关闭当前进程并自动重新拉起应用，方便切换「透明效果」等需要重启生效的选项。
- **更新弹窗支持 Markdown 排版**：版本更新弹窗改用轻量 Markdown 渲染，标题、列表、加粗与链接可正常排版与点击，不再显示原始符号。
