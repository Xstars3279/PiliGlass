# UI 改版清单

改版只在「悬浮底栏 + 液态玻璃悬浮底栏」都开启时生效（`lib/common/revamp.dart` 的 `Revamp.enabled`），关掉即回到原版界面。

原则：只换皮不动骨（不改控制器和数据逻辑）；能在全局主题里解决的，不逐页修改。

## 已完成

- [x] 弹簧动效库 `lib/common/motion`（按压回弹、弹簧滑动、松手吸附）
- [x] 液态玻璃悬浮底栏 + 右侧搜索按钮，滚动时缩成小圆
- [x] 视差页面转场 + 全屏右滑返回（GetX 补丁 `tool/patches/getx_custom_transition.patch`）
- [x] 首页：单行分区 Tab
- [x] 搜索页：底部输入框，与底栏变形衔接
- [x] 视频卡片新样式（竖版/横版），封面飞入播放器，首帧前显示封面
- [x] 播放页：封面取色氛围背景，点赞/投币/收藏弹跳粒子
- [x] 「我的」页：头像模糊横幅、数据卡片、圆角分组
- [x] 「我的」页菜单：离线缓存、观看记录、收藏、稍后再看、订阅、设置、关于并列成带彩色小图标的行；有预览的行点一下就地展开
