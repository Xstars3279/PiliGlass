# PiliGlass v0.2.1

从 v0.2.0 到 v0.2.1，这一版把玻璃再往下做了一层：四档透明度、会从按钮里长出来并缩回去的锚定菜单，以及铺开到各页面的玻璃返回键。

仅支持 **Android arm64-v8a**，签名与之前一致，可直接覆盖安装（Android 8.0 以上）。

## 玻璃

- 透明效果由三档扩为 **无 / 标准 / 增强 / 极致** 四档。增强保留 v0.2.0 的观感，极致回到 v0.1.4 的透明液态玻璃：底栏更透，面板也开始折射背后的内容。默认增强，切换后重启生效。
- 菜单有了自己的透明度：无档不透明，标准、增强、极致依次更透，极致下能清楚看到背后的内容。
- 底栏与顶部标签的选中胶囊在极致下为 70% 不透明度，移动时像一块带色的镜片，而不是实心色块。
- 玻璃提示（Toast）改为跟随透明档位的液态玻璃胶囊，不再是固定的不透明反色块。

## 动效与菜单

- 锚定弹出菜单重写：按下按钮时，菜单从按钮的位置长出来；按钮先截图并隐藏，收起时画面缩回按钮，再把按钮放出来，不再是一整块淡入淡出。
- 生长与收拢改用弹簧曲线：卡片从一小滴液体展开，圆角随之收方，边缘带轻微回弹；收起时反向回流。
- 菜单覆盖在按钮上，去掉了向下的 6dp 间隙；宽度下限收到 160。
- 不在滚动区域时按下即开；在列表里先等一个按压阈值，避免抢走滚动。同一根手指可以滑进菜单，逐行高亮，松手选中，并带选择震动。
- 所有玻璃按钮和底栏项加入按压膨胀与橡皮筋拖动；评论区、弹幕、播放设置和清晰度面板从对应按钮向上生长。

## 底栏与顶栏

- 底栏选中胶囊改为同心圆角：胶囊高 56，四周内缩 4，内部底板略宽，贴合栏体。
- 顶栏的隐式返回箭头统一换成玻璃圆钮，通过 `ActionIconTheme` 只替换图标，不改变原有槽位、点击、提示和栏高。

## 个人页

- 顶部标签胶囊改为居中，并收窄到标签本身的宽度。
- 右上角搜索和更多改为独立的小玻璃圆钮（46 圆、48 点击区、22 图标），间距 8，不再包在一条大胶囊里；有预约时预约按钮仍单独排列。
- 有大图和无大图两套顶栏都加上玻璃返回圆钮。

## 返回按钮

- 新增统一的 `GlassBackButton`：页面内是浅色玻璃圆钮；视频、直播等封面上是 32% 黑色的烟熏圆钮，带按压膨胀和橡皮筋拖动。
- 覆盖视频详情（竖屏与全屏）、直播间、个人页、我的、专栏列表、动态发布/转发、音乐/MV、搜索趋势、订阅详情、日志和 WebView 等页面。

## 修复

- 玻璃 Toast 的 `Align` 补上 `heightFactor: 1`，胶囊按文字高度收缩，不再被撑到屏幕中央。
- 按压变换补上 `applyPaintTransform` 和反变换命中测试，按钮膨胀或拖动时，点击区域与看到的形状一致。
- 锚定菜单去掉了额外的对话框淡入；菜单生长时不再整屏闪一下。
- 菜单的快照改由路由持有并在收起后释放，离开页面时不会留下残影。
