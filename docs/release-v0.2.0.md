# PiliGlass v0.2.0

从 v0.1.4 到现在，把界面从头走了一遍：设计令牌、卡片和列表、视频与播放器、动态与直播，以及顶栏、底栏和玻璃细节。

仅支持 **Android arm64-v8a**，签名与之前一致，可直接覆盖安装（Android 8.0 以上）。

## 更统一的界面

- 颜色、间距、圆角、字号集中到 `ui_tokens.dart`，页面里的零散尺寸明显减少。
- 卡片、封面、菜单、对话框统一使用连续曲率圆角，转角更平滑。
- 图标换成圆角 Material Symbols，选中态使用填充样式。
- 视频卡重画：竖版封面压暗、数字统一；新增横版卡，用于评论、收藏、历史等列表。
- 「我的」页、设置页、菜单和对话框统一分组、行高与留白。

## 视频详情与播放器

- 视频详情页整页重画：封面取色淡洗背景、UP 行与标题、操作栏、评论卡和番剧剧集芯片一起调整。
- 播放器倍速、清晰度使用黑色玻璃菜单；菜单变窄到 112，行高收到 35。
- 全屏控制收成一行：播放、时间、弹幕输入、字幕、倍速、清晰度和退出全屏。
- 全屏控件采用播放器专用紧凑规格：**42×34 控件、20 图标**，不再机械套用其他页面的 48dp 大按钮。
- 返回、更多、点赞/投币/收藏、底部字幕与全屏按钮统一图标尺寸。
- 弹幕输入框降到 32 高，弹幕开关和弹幕设置统一为紧凑圆钮。
- 右上角 `⋯` 面板收窄到 360，普通行高收到 40，面板图标统一为 20；带副标题的行仍会自动撑高。
- 时间放回播放键旁；「选集」「画面比例」「高能进度条」等保留在全屏 `⋯` 里。

## 动态、直播、评论与聊天

- 动态页左栏收窄，头像、行高和帖子留白统一；栏顶与卡片从顶栏下方开始。
- 直播间按视频卡样式重画，标签行右端渐隐，没人直播时不再显示空的关注行。
- 评论区改为实白面板与拖动条，输入条带渐隐；子回复使用中性色块。
- 聊天气泡、时间显示和 Toast 胶囊统一尺寸与圆角。

## 顶栏、底栏与玻璃

- 首页和动态页共用居中的玻璃标签，点击和左右滑动都跟手，文字颜色同步渐变。
- 首页左上角头像只在底栏作为主导航时显示。
- 透明效果保持「无 / 标准 / 极致」三档，默认极致，同时作用于外壳和面板。
- 修复首页顶栏局部有底色没模糊、快速滚动时胶囊残留清晰画面等问题。

## 修复

- 选集芯片按文字宽度排版，进入剧集自动滚到当前集。
- Toast 胶囊按文字宽度显示，不再拉满屏幕。
- 评论面板里的合集列表可以滚动，子面板会跟着面板一起拖动。
- 透明档位选「无」时，不再残留顶栏和底栏的硬渐变。
