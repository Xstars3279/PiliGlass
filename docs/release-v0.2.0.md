# PiliGlass v0.2.0

把界面从头走了一遍：一套新的设计令牌、重新画过的卡片和列表、播放器与全屏、动态与直播，以及顶栏和底栏的玻璃细节。

仅支持 **Android arm64-v8a**，签名与之前一致，可以直接覆盖安装（Android 8.0 以上）。

---

## 一套更克制的设计

- **设计令牌集中在一处**：颜色、间距、圆角、字号都收进 `ui_tokens.dart`，页面里不再散落魔法数字；页面是浅灰底 + 白卡片，界面中性、留白稳定。
- **连续曲率圆角**：卡片、封面、菜单、对话框、胶囊全部换成连续曲率，转角不再是生硬的圆弧。
- **图标换成 Material Symbols**：圆角风格，选中态填充；外壳（底栏、侧栏、顶栏标签、圆按钮）先用上，上游页面保持原样，合并不受影响。
- **视频卡重画**：竖版封面 40% 压暗、数字 11/500、更多按钮 40 点击区；新增横版卡 140×16:10、圆角 12，用在评论、收藏、历史这类列表里。
- **列表与设置**：分组标签、56 高的行、细线分隔、账号卡置顶、退出登录沉底。
- **菜单与对话框**：180–280 宽、48 行高、危险操作红色置底；深色下改为描边。
- **「我的」页**：去掉卡片底的头像区，64 头像、整行昵称、连续的经验条。

## 视频详情、播放器、全屏

- **详情页整页重画**：封面色 12% 淡洗背景；弹幕框 36 + 36 圆钮；UP 行与标题 17/600；三条操作 24 图标、56 高；评论卡白底单行；番剧海报 96、剧集芯片 140×56，芯片按文字宽度。
- **播放器**：遮罩 60% / 70%；倍速、清晰度是黑 72% 玻璃菜单，圆角 24、120 宽，放不下时菜单内部滚动；全屏时把数字挪到进度条两端。
- **全屏控制**：上下各一条，48 点击区、24 图标、不带圆底；「⋯」里是回到主页、分享、画中画、选集、画面比例、高能进度条、翻译。
- **订阅/番剧**：选集入口写「查看全部」，不再重复「已完结 · 全 N 话」；进入剧集自动滚到当前集。

## 直播、动态、评论、聊天

- **直播**：直播间按视频卡画，无外框、40% 压暗、11/500 数字；标签行右端渐隐；没人直播时不再显示关注行。
- **动态页**：左栏收窄到 48、头像 40、行高 68，帖子左右各留 8，右侧面板往左扩，两栏之间的空白和左侧留白一致；栏顶和卡片一样从顶栏下方开始。
- **评论区**：实白面板 + 32×4 拖动条，输入条 44 带渐隐；子回复改成中性色块，操作行降为次级。
- **聊天**：气泡圆角 24、发送者一侧的角 8，自己的用主色、对方白底；时间每分钟只出现一次。
- **Toast**：白色反色胶囊，高 36，宽度跟着文字走。

## 顶栏与底栏

- **顶栏标签居中**：首页和动态页共用一条居中的玻璃胶囊，胶囊由 `TabController.animation` 逐帧驱动——点标签和左右滑页面都跟手，文字颜色同步渐变；一行放不下时横向滚动、边缘 24 渐隐，选中的标签会滚到中间。「设置 → PiliGlass 特性 → 顶栏标签居中」可以立刻关掉。
- **首页头像**：左上角 32 圆头像，点一下进「我的」；用侧栏时不再重复显示。
- **白色渐隐遮罩**：顶栏和底栏背后各一层，屏幕边缘是纯白，到栏的中线完全透明（顶栏 30、底栏 40），内容从栏下穿过时不再硬切。
- **透明效果三档**：「无 / 标准 / 极致」，默认极致（75%，带折射），同时作用于外壳和面板。

## 修复

- 首页顶栏左侧一截「有底色、没模糊」，静止也不恢复；快速滚动时胶囊里偶尔残留一块清晰的 feed——顶栏改走页面 appBar，玻璃的裁剪和背景层每次绘制重建。
- 选集芯片按文字宽度排版，进入剧集页自动把当前集滚进视野。
- Toast 胶囊按文字宽度显示，不再拉满屏幕。
- 透明档位选「无」时，首页顶栏和底栏下面残留的硬渐变遮罩已去掉。
- 评论面板里的合集列表可以滚动，子面板会跟着面板一起拖动。
