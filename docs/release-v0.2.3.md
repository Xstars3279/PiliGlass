# PiliGlass v0.2.3

本版本基于 **PiliPlus 2.2.1**（`v0.2.2`）新增了本地 MP4 无损合并下载功能，并对设置分组、弹窗玻璃效果与描边、搜索页排版以及横屏/侧栏布局问题进行了集中优化与修复。

仅支持 **Android arm64-v8a**，签名与之前一致，可直接覆盖安装（Android 8.0 及以上）。

## 新增功能

- **本地视频 MP4 合并下载**
  - 新增本地无损合并导出 MP4 功能：通过 Android 原生 `MediaExtractor` + `MediaMuxer` 将音视频分片封装为标准 `.mp4`（自动避开不兼容 MP4 封装的杜比视界与 Hi-Res/杜比音轨并选用兼容流）。
  - 视频播放页右上角 `...` 菜单与三连操作栏最右侧均新增 **「下载视频」** 入口。
  - 新增 **「我的下载」** 管理页：支持查看下载/合并进度、失败重试、点击已完成视频跳转外部播放器打开，以及删除/清空记录弹窗（支持勾选「同时也删除本地视频文件」），右上角可直接跳转下载设置。
  - 原「播放」设置分组升级为 **「播放与下载」**，新增 **「下载设置」**，支持自定义默认下载路径（SAF 目录或系统 `Movies/PiliGlass`）、默认下载画质与默认下载音质。
  - 在 **「我的」页** 与 **「外观设置 › 我的页卡片」** 加入「我的下载」（默认开启，保留原有卡片配置并自动开启一次）。
- **下载与缓存面板多选改造**
  - 本地下载面板与离线缓存面板改为点击条目打勾多选，底部改为三段式操作栏：**「全选 / 取消全选｜下载(缓存)所选(x项)｜查看下载(缓存)」**；画质、音质下拉改用按钮处钻出的玻璃弹出菜单。

## 界面与交互优化

- **设置页分类与控件体验**
  - 为推荐流、音视频、播放器、下载、外观、其它等二级设置页面按模块加上分组标题与独立卡片。
  - 设置页下拉选择项将当前选项移至右侧与上下行开关对齐，支持从右侧文字处弹出玻璃菜单并拖拽滑选。
  - 外观设置右上角新增 **「重启软件」** 快捷按钮。
- **玻璃质感与弹窗对齐**
  - 为浅色模式下的各类玻璃组件统一加上细腻浅灰外描边；优化弹窗纯白透底玻璃效果与浅色背景遮罩，并接入按压跟手弹性交互。
  - 统一「账号切换」及各类单选/多选设置弹窗的标题、选项缩进与 `48dp` 行高。
- **搜索、动态与浏览器细节**
  - 搜索结果页「综合、番剧、影视…」标签栏恢复为原生标签样式；统一搜索页「大家都在搜」「搜索历史」「搜索发现」卡片内边距与行距。
  - 动态页各处 `...` 菜单改为从底部弹出；内置浏览器右上角菜单统一为玻璃样式；优化 `...` 菜单关闭时的原生分辨率快照过渡。

## 问题修复

- **横屏顶栏与侧栏**：修复横屏/宽屏侧栏模式下首页与动态页顶部出现双倍状态栏间距的问题，并加深顶部状态栏渐变遮罩；修复开启「改用侧边栏」后侧栏未生效且首页头像、消息图标消失的异常。
- **网络与打包**：补充本地打包与发布指南文档（`docs/release-build.md`），并微调链接打开及网络请求相关逻辑。
